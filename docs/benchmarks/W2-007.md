## 2. 计数正确性 / 差分证据

判据清单（统一枚举 `FastFilterKind`）：`zip_verifier`、`sevenz_first_block`、`rar5_check_value`。

- **公式**：E2E `w2_007_filters.rs` 对 ZIP 否决/命中、7z 默认/严格、批量报告均断言 `attempts = fast_rejected + full_attempted`；`external_attempts ⊆ full_attempted` 由 RAR 计数实现与 `external attempts=0`（ZIP/7z）断言覆盖。
- **ZIP 误杀**：20 个错误候选 + 1 个正确候选的单元用例要求每个变体恰好落入一个桶（合计 21），错误候选均返回 `Miss`、正确候选返回 `Hit`；AES 同型用例合计 3。ZipCrypto 1/256 检查头碰撞会使个别错误候选落入 `full_attempted` 而非 `fast_rejected`，但不会改变命中结果。
- **7z 误杀 / strict 覆盖**：默认模式首块探测否决计入 `sevenz_first_block`；`--strict` 下 `fast rejects=0`、`sevenz_first_block=0`、`full attempted=2`（两个错误候选全部走完整 CRC），命中仍由完整 CRC 产生。
- **实测输出样例**（`w2_006_encoding.rs` 的 GBK ZIP 场景，修复旧恒零断言时观察到）：

```text
Stats: encoding attempts=2 (candidates=1, skipped variants=1), fast rejects=1 [zip_verifier=1, sevenz_first_block=0, rar5_check_value=0], full attempted=1, external attempts=0, external confirms=0
FOUND: 中文密码
```

- **编码跳过不双重计数**：审阅后新增 `ArchiveSession::was_variant_skipped()`，7z 非 UTF-8 与 RAR OEM 不可表示的变体由引擎标记跳过，`EncodingSession` 撤销该次 `attempts`，`job_stats` 仍把 `encoding_skipped` 汇入 skipped，从而同时满足 `attempts = fast + full` 与 `variant_slots = attempts + skipped`；`encoding.rs` 用 stub factory 单测覆盖。
- **RAR 计数实测**：本机 UnRAR 6.24 下 `local_rar5_fast_filter_counts_external_calls` 验证默认模式 `fast rejects=1 / rar5_check_value=1 / external attempts=1`，`--rar-no-fast-reject` 下 `fast rejects=0 / external attempts=2`，且 `external attempts <= full attempted` 与公式成立。
- **0 误报**：本切片不改变命中复核路径——ZIP/7z 仍由内置引擎完整解压/CRC/HMAC 决定，RAR 仍由外部 `UnRAR t` 决定；W1 10⁷ ZIP 负例证据继续有效。
- **0 漏报**：默认与 `--strict` 在上述语料上命中率一致（同为 1/1 命中），差异只在快筛否决计数。

## 3. 性能 before/after

- **ZIP：不适用**。确认 `zip` crate 的 `by_index_decrypt` 已在完整解压前完成 ZipCrypto check header / AES verifier 检查（`archive/zip.rs:4-12`）。新增第二个 verifier 只会重复 KDF/检查，不满足 W2-007 P1「实测证明减少完整验证成本」的前提，因此本切片**不新增 ZIP 判据**，只把 crate 已有否决纳入计数。没有可宣称的吞吐 before/after 百分比。
- **RAR4：不适用**。`-hp` 评估结论为 no-go（见 `docs/analysis/rar4-hp-header-feasibility.md`），外部调用次数不下降；`external_attempts` 已能量化实际调用。
- **计数开销**：新增的是每候选 1–2 次原子自增；未做 1M 级 before/after 基准，不给出性能数字。
