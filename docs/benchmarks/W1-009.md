# W1-009 RAR5 快速校验基准

- **状态**：完成（基准与差分为本机语料；更广泛的第三方 `-hp` 样本待补）
- **日期**：2026-11-26
- **主机**：Windows 11 build 26300；i5-14600K（14C/20T）；31.7 GB RAM
- **CLI**：release `acx.exe`，`-t 14`
- **语料**：1.3 GB `rar单个压缩.rar` + 1M 合成错误候选（15 MB，gitignored）
- **对照**：W1-008 外部整包 `UnRAR.exe t`，4515.104 s / 221.5 候选/s

| 指标 | W1-008 外部 | W1-009 check 快筛（4096 窗口） | 变化 |
|---|---:|---:|---:|
| 1M RAR5 wall | 4515.104 s | **578.958 s（9.65 min）** | **7.80×** |
| 吞吐 | 221.5/s | **1727.2/s** | 7.80× |
| parent peak RSS | 3.1 MB | 3.1 MB | — |
| parent CPU | 4070.797 s | 4959.391 s | 8.56 / 20 逻辑核 |
| 退出 | 1 | 1 | NOT FOUND |

> 2026-11-26 复核：为满足 W1-006 硬杀 ≤4096 候选窗口，scheduler 将总 in-flight 候选限制为 4096（本机 14 线程时 per-batch=240）。因此 RAR5 1M 从早先 424.838 s 调整为 578.958 s；仍比外部整包 4515.104 s 快 7.80×。

说明：

- 快筛只对 ASCII 候选启用；非 ASCII 回退外部 `UnRAR t`，不计入此吞吐。
- 命中仍由外部 `UnRAR.exe t` 复核；快筛只否决，不直接输出 `FOUND`。
- RAR4 不启用快筛，仍按 W1-008 路径。
- 头加密（`-hp`）已用本机 `Rar.exe` fixture + CLI FOUND 验证；仍需更多第三方 `-hp` 样本。
