## 2. 差分 oracle（`core/crates/acx-cli/tests/w2_008_differential.rs`，本机 5/5 执行）

本机 7-Zip / UnRAR 均存在，5 个用例实际执行且通过；工具缺失时 ZipCrypto 与 RAR5 用例会打印跳过信息并返回，不计为"通过"。

| 用例 | oracle | 结论 |
|---|---|---|
| ZipCrypto 命中/错误密码 | 7-Zip `t -p` | acx 与 oracle 一致；计数公式成立 |
| AES ZIP `zip_verifier` 桶 | **无外部 oracle** | 仅断言命中与 `zip_verifier` 计数非零；不声称与 7-Zip 对照 |
| 7z 默认 / `--strict` | 已知中文密码（非外部 oracle） | 两者均命中；strict 下 `sevenz_first_block=0`；未构造"正确密码被首块误拒"样本 |
| RAR5 外部调用 | UnRAR `t -p` | 命中/未命中和 oracle 一致；`external attempts ⊆ full attempted` |
| 截断 ZIP | — | 按归档错误返回退出码 3，不静默判 Miss；该用例不校验计数公式 |

计数公式在 4 个候选验证用例中显式断言：`encoding attempts = fast rejects + full attempted`，`external attempts <= full attempted`；截断用例只做错误分类。

## 3. W2-007 快筛证据（真实运行样例）

1M 字典攻击的实测统计行：

```text
Stats: encoding attempts=999720 (candidates=999720, skipped variants=0), fast rejects=999707 [zip_verifier=999707, sevenz_first_block=0, rar5_check_value=0], full attempted=13, external attempts=0, external confirms=0
```

- `attempts = fast + full` 成立（999720 = 999707 + 13）；`external attempts=0` 因 ZIP 不走外部进程。
- 误杀证据边界：唯一已知密码落入 `full_attempted` 并由完整 CRC/HMAC 复核命中；其余 999,719 个候选未逐候选做完整复核，因此这条统计行**不能单独证明 0 误杀**。0 误杀证据来自 W2-007 小型负例差分（21+3 候选）与本次 ZipCrypto/RAR5 oracle 差分，不来自 1M 统计行。
- 0 漏报：差分用例中默认与 `--strict` 对已知密码均命中；1M 规模未做默认/strict 全量命中率对照，此口径只到小语料级。
- RAR4 `-hp`：维持 no-go，所有候选继续外部 `UnRAR t`，报告中只给出 `external attempts` 实测，不宣称外部调用下降。

## 4. 1M 基准矩阵

同一 release 二进制、14 线程、合成小条目 ZIP AES 夹具，**仅 ZIP 一种格式**；7z/RAR 的 1M 基准未测。任务 F4 原写 × ZIP/7z/RAR，本切片按本机预算裁剪为 ZIP 四模式，并在验收中记为未验证项。注意：**这些数字与 W1 的 1 GB 归档基线不可直接比较**（条目大小不同）。`--estimate` 的原始输出未写入 `bench-raw.json`，ETA 表为报告时手工记录，唯一可比样本是 hybrid。

| 模式 | 键空间 | 实际 attempts | wall | p/s（attempts/s） | CPU s | 峰值 RSS | 命中 |
|---|---:|---:|---:|---:|---:|---:|---|
| 字典 | 1,000,001 | 999,720 | 40.242 s | 24,842.9 | 545.641 | 8.2 MB | 是 |
| 掩码 `?d`×6 | 1,000,000 | 122,776 | 5.039 s | 24,364.4 | 66.188 | 7.2 MB | 是（122,776 处提前命中） |
| 暴力 `?d` 1–6 位 | 1,111,110 | 234,013 | 10.099 s | 23,171.7 | 126.906 | 7.2 MB | 是（234,013 处提前命中） |
| 混合 1k 字典 × `?d?d?d` | 1,001,000 | 1,001,000 | 40.233 s | 24,880.2 | 542.594 | 7.3 MB | 是（末尾命中） |

说明：

- 掩码/暴力在键空间中段命中，wall 时间不能用于推算全键空间吞吐；p/s 按已完成 attempts 计算。
- 字典 attempts 少于字典行数，是命中停止时仍在飞行的批次未计入已完成数，属调度器既有语义（W1-006）。
- 混合总候选为 1000 行 × 1001 变体（含 identity），与 `--estimate` 输出一致。
