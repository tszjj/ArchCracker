# W1-008：正式基准与 W1 收口证据

- 状态：完成（三格式 1M×1GB 实测；正确性长跑见 W1-010）
- 门禁：W1 准出/W2 准入前的最后证据切片
- 角色：qa-engineer、release-engineer
- 分支：`feat/w1-008-benchmark`
- 依赖：W1-001…W1-007
- 范围：1M 字典、1GB+ 归档、吞吐、CPU、内存、ETA；不含新算法、GPU、界面

## 设计目标

解决「W1 到底能不能准出」的证据问题。面向 W1 收口评审，用可复现脚本对 ZIP/7z/RAR 做同机同语料的正式实测，记录吞吐与资源消耗，用数据决定准出，而不是把未跑的项目写成通过。

## 已确认的成本

- RAR 每个候选启动一次外部整包测试，1M 约 75 分钟，成本最高；
- 7z 每个候选都有 AES 密钥派生，1M 约 21 分钟（14 线程）；
- ZIP AES 1M 约 42 秒；
- 用户的大归档/字典不提交仓库；基准只记录文件大小、条目数与命令，不记录密码。

## 基准矩阵

| 格式 | 归档 | 候选 | 结果 |
|---|---|---|---|
| ZIP AES | 1.3 GB | 1M 错误 | 42.247 s，约 23,670/s，常驻内存 3.1 MB |
| 7z AES | 1.3 GB | 1M 错误 | 1271.049 s（早期基线）；4096 窗口复测 1033.040 s / 967.9/s |
| RAR5 | 1.3 GB | 1M 错误 | 4515.104 s（外部基线）；快筛 578.958 s / 1727.2/s |
| 已知密码 | 测试夹具 | 各格式 | 既有集成测试 100% |

## 验收与口径

- release 二进制 + 可复现脚本 [bench-w1.ps1](../../scripts/bench-w1.ps1)；
- 三格式 1M 均实际完成，吞吐、常驻内存、CPU 已记录，结果写入 [W1-008 基准报告](../benchmarks/W1-008.md)；
- 三格式 1M × 1GB 性能门禁实测通过，RAR 成本最高；
- CI/MSRV/release/cargo-deny 与基准同提交；
- ZIP 10⁷ 长跑、7z/RAR 10⁵ 差分矩阵、暂停/停止时延矩阵在 W1 准出评审中逐项确认，不由本基准替代。

## 许可与引用

用户语料与密码不提交仓库，基准报告只保留可复现命令与语料特征。

## 评审与对照意见

准出数字以 W1-010 的 4096 窗口复测为准（ZIP 39.335 s / 25,423/s；7z 1033.040 s / 967.9/s；RAR5 578.958 s / 1727.2/s），本页早期数字仅作历史记录。当时未验证：ZIP 10⁷ 长跑、暂停/停止时延矩阵、7z/RAR 10⁵ 完整差分，均已由 W1-010 补齐。
