# W1-009：RAR5 快速密码校验

- 状态：完成（评审通过，法务复核附条件通过；更广泛第三方头加密语料为后续质量项）
- 分支：`feat/w1-009-rar5-fast-check`
- 依赖：W1-003/003b/003c、W1-008
- 角色：core-engineer、reviewer、release-engineer（许可复核）
- 范围：RAR5 进程内校验快筛、外部 `UnRAR.exe t` 命中确认、许可文档；不含 RAR4 快筛、RAR 解压/压缩、GPU

## 设计目标

解决「RAR5 每个候选都要启动一次外部进程、1M 要跑 75 分钟」的问题。面向 RAR5 大字典场景，在进程内用加密头里自带的校验值快速否决明显错误的候选，把外部进程只留给可能的命中，在保持零误报的前提下把吞吐提升一个数量级。

## 实现要点

- 新模块 `archive/rar5_verify.rs`：解析 RAR5 头加密或文件加密记录中的密钥派生参数与 12 字节校验值；前 8 字节与后 4 字节做 SHA-256 校验；用 PBKDF2-HMAC-SHA256 派生并折叠为 8 字节比对。
- 只对 ASCII 候选启用；RAR4、非 ASCII、无校验值、解析失败一律回退外部进程，保证正确性优先。
- `RarSession::test_password`：快筛否决则未命中；通过或回退则仍由外部 `UnRAR.exe t` 复核，退出码与命中语义不变。
- `RarFactory` 创建时解析一次校验值供所有线程复用，不增加每候选文件读取。
- 依赖：`sha2` 直接依赖（原已是传递依赖），不新增 RAR 库。

## 验收

- 密钥派生已知向量、本机生成的 RAR5 文件加密与头加密样本、正确/错误密码均通过；
- 完整 CLI RAR5/RAR4/Unicode/分卷/SFX 回归通过；
- 1M RAR5 实测 578.958 s / 1727.2/s，对比 4515.104 s / 221.5/s，提升 7.80×（4096 在飞窗口）；
- 命中仍由外部复核；非 ASCII、无校验值、校验失败、派生次数超限均正确回退；
- fmt/clippy/MSRV/release/cargo-deny 全绿。

## 许可与引用

快筛只做密钥派生与校验值比对，不做解密/解压；不实现 RAR 解压/压缩，不复制或链接 UnRAR 源码。任何扩展到数据解密都需重新做 ADR 与许可评审。许可分析属工程判断，已按项目负责人确认完成法务复核（附条件），发布前由 release-engineer 按条件检查。相关文档：ADR-0005、ADR-0003、`docs/licensing.md`、`docs/architecture.md`。

## 评审与对照意见

评审与法务复核通过。已知边界：非 ASCII 候选仍走外部，中文/Unicode 字典提升有限；RAR5 校验是 64 位判据，匹配仍由外部确认，零误报目标不变；RAR4 无等价校验，不在 W1 性能承诺内；头加密已用本机样本验证，更广泛第三方样本待补。派生次数有上限（24），损坏或恶意参数一律回退。
