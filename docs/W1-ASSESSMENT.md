## 2. 证据

### 功能/正确性

- 98 core + 39 CLI（1 ignored）+ 2 FFI；CI workflow 全绿（PR #10–#15）。
- 已知密码：ZIP/7z/RAR5/RAR4/Unicode/分卷/SFX 集成测试通过。
- 1M 错误候选：ZIP/7z/RAR5 均为 `NOT FOUND`，未出现误报/异常退出。
- ZIP 10M 负例：393.569 s / 25,409/s，0 误报（[W1-010 基准](benchmarks/W1-010.md)）。
- 错误分类：缺卷/截断/损坏/未加密有测试；RAR 损坏仍部分走 External（文档已列）。
- 硬杀窗口：4096 in-flight 候选限制；本机 14 线程 30 s kill 实测 `tried-completed=1242`，新增单测断言 ≤4096。

### 性能

### 许可

- ADR-0005 **Accepted（2026-11-26 法务复核附条件通过）**；
- 独立 KDF/check，不复制/链接 UnRAR，不实现解压/压缩，命中仍外部 `UnRAR t`；
- 非 ASCII 快速路径未启用，回退外部；
- 发布前 release-engineer 仍需按 ADR-0005 条件复核。
