## 1. 先回答定位问题

**W2-008 是 W2 的一个切片（最后一个证据切片），不是 W2 阶段目标本身。**

- **W2 阶段目标**（`docs/W2-PLAN.md` §1）：在 W1 的 ZIP/7z/RAR + 字典 + 流式 + 断点基础上，补齐 CPU 攻击面、批量和编码变体，使 Windows CLI 达到 beta 可用。
- **W2-008 的职责**：为上述目标提供可复现证据——语料/差分/基准/Windows 全栈验证。它是准出的**必要条件**，但不是充分条件；即使 W2-008 全绿，若质量门禁或许可边界不满足，W2 仍不能签核。
- **W2-001 GPU/hashcat** 已 Deferred，不阻塞 W2 准出；GUI、安装包、其他平台均不在 W2 范围。

## 5. 本地开发模式下的两级结论

为避免把"本地验证"写成"CI 验证"，准出结论分两级：

- **条件准出（本地）**：功能、正确性、性能、许可、文档在本地证据下满足；CI 未运行项明确列为"未验证"。可用于内部推进 W2-008 与 W3 准备，但**不宣布 W2 正式签核**。
- **正式准出（签核）**：P4 完成后，把 CI 6/6 链接补入证据表，创建 `W2-SIGNOFF.md`，才宣布 W2 关闭。

CI 恢复条件与备选通道见 `docs/DEV-ARCHIVE-2026-11-28.md` §5 与先前讨论的自托管 runner / 公开仓库方案。

## 6. 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| CI 额度未恢复 | 正式签核无法完成；跨平台编译未验证 | 本地门禁顶住；恢复后重跑；必要时切自托管 runner |

| 7z 无认证器 | 损坏归档可能表现为 NOT FOUND | 不承诺候选级密码错/损坏二分，统一 Miss |
| 统计行格式扩展 | 下游位置敏感解析器需适配 | 发布说明标注；仓库内无此类解析器 |
| 状态漂移 | 文档与代码不一致 | 每个切片完成后同步 PROJECT-GUIDE / W2-PLAN / 任务文档 |
