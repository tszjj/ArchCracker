# CL-W3-001：C ABI v1 冻结

- 分支：`windows-gui`
- 基线提交：`a34e0eb feat(ffi): implement C ABI v1`（评审前）；修复提交待回填
- 关联阶段：W3-001（C ABI v1 冻结）
- 影响范围：`acx-ffi`、`acx-core` 的可选进度钩子、CI ffi-smoke job、架构/W3 文档

## 1. 变更说明

1. `acx.h` 升为 `ACX_ABI_VERSION 1`，冻结 `AcxConfig`、`AcxInput`、`AcxAttackSpec`、`AcxCallbacks`、`AcxStatusInfo`、`AcxEstimateInfo` 与函数表。
2. `acx-ffi` 实现句柄生命周期、结构体/枚举校验、字符串拷贝、错误码映射、panic 隔离、回调门控、后台 worker、`acx_status`、`acx_last_error` 与 `acx_estimate`。
3. `acx-core` 新增 `run_job_with_progress` / `ProgressHook` / `ProgressReporter`；原 `run_job` 保持签名与行为不变，CLI/batch 不受影响。
4. 新增 C99/C++17 header smoke、C# .NET 10 `LibraryImport` smoke（两种回调模型均实测）与 CI `ffi-smoke` job。
5. 按评审修复：进度终态快照、on_finished 语义、终态防覆盖、last_error 稳定副本、start/stop 并发竞态、回调重入防护、估算 API、跨语言布局断言。

## 2. 验收条件

- FFI 8 个单元测试 + 4 个 E2E 全部通过；
- C99/C++17 header smoke 通过（含冻结结构体尺寸断言）；
- C# smoke 输出 `UCO=True delegate=True chosen=UnmanagedCallersOnly`；
- `fmt`、`clippy -D warnings`、`cargo test --workspace`、MSRV 1.89、`cargo-deny`、release 全绿；
- reviewer/architect/release 复审通过后才进入 W3-002。

## 3. 风险

- v1 已冻结，后续破坏性改动必须提升 ABI 版本；
- fd/uri 仅 ABI 槽位，JNI/NAPI 生命周期尚未验证；
- 回调用户指针必须在 `acx_destroy` 前保持有效，回调内禁止重入 `acx_*`；
- C# 回调模型实测后选择 `UnmanagedCallersOnly`，delegate 模型保留 smoke 验证；
- sidecar 未实现，自动解压不做。

## 4. 回滚方案

- 本分支未推送时：本地 `git reset --hard fe02141` 回到 W2 基线；
- 已推送时：`git revert <W3-001 merge/commit>`，同时撤销 `acx.h` v1、FFI 实现、`run_job_with_progress`、CI ffi-smoke job 与相关文档；
- 回滚影响：W3-002 不得继续按 v1 对接；断点 schema v2 与 CLI 行为不变，回滚不需要数据迁移。
