## 1. 变更说明

在 W2-006 的开关与基础计数之上，补全 W2-007 的判据接入与缺失指标：

1. 新增 `acx_core::archive::filters`：`FastFilterKind`（`zip_verifier` / `sevenz_first_block` / `rar5_check_value`）与 `FilterCounts`，统一判据标识与按判据计数。
2. `ArchiveStats` / `JobStats` 增加 `full_attempted`、`external_attempts`、`by_filter`；`job_stats()` 按 baseline 差分汇总，接入 `--report-stats` 与批量每任务报告。
3. ZIP：确认 `zip` crate 已在完整解压前做 verifier，不新增重复判据；把 `InvalidPassword` 计入 `zip_verifier`，`ZipFactory` 实现 `stats()`（修复此前恒 0）。
4. 7z：首块探测否决计 `sevenz_first_block`，完整 CRC/头加密解析计 `full_attempted`；`--strict` 仍关闭探测。
5. RAR5：现有 ASCII 快筛以 `rar5_check_value` 接入；每次外部进程调用计 `external_attempts`（⊆ `full_attempted`），命中才计 `external_confirmed`。
6. 新增 `ArchiveSession::was_variant_skipped()`：7z 非 UTF-8 与 RAR OEM 不可表示变体标为 skipped，撤销对应 `attempts`，避免与 `skipped` 双重计数，守恒 `attempts = fast + full` 与 `variant_slots = attempts + skipped`。
7. 契约补丁：ZIP verifier 作为「可证明精确、不漏报」的唯一例外不受 `--strict` 关闭，已在任务文档 §2/F2/F5 显式登记。
8. 产出 RAR4 `-hp` 首头校验 no-go 报告；RAR4 含 `-hp` 继续外部 `UnRAR t`。
9. 断点 schema v2 不升版；无可配置判据参数，默认攻击签名不变。
